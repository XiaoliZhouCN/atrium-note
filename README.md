# ChestNote

## 项目概述
ChestNote 是一个用于整理个人笔记、技术杂记与临时记录的轻量仓库，主要用于长期积累、分类归档与持续查阅。

## 仓库定位
- 收纳日常开发与使用过程中产生的零散记录
- 整理配置方法、操作流程与常用参考内容
- 作为个人知识仓库持续补充与维护
- 为后续加入 Python 小工具或其他轻量脚本预留空间

## 当前内容
当前仓库已包含以下内容：
- `gitconfigs/confignotes.md`：记录不同设备下的配置方式、仓库拉取流程与基础初始化说明
- `.log`：记录当前阶段的工作内容，标题使用英文，内容使用中文；其中 `[MB]` 表示记录生成于 Huawei MateBook，`<!!>` 表示该条记录已推送到仓库
- `gitpush.bat`：根据 `.log` 中的最新记录整理提交信息，用于配合当前日志维护流程进行推送
- `career/`：维护职业规划、岗位画像、成长路线图与阶段性复盘框架
- `education/`：维护长期语言能力、专业课程能力与阶段性深造目标，其中包含留学申请专题

## 后续扩展方向
- 按主题整理的分类笔记
- 用于快速处理问题的 Python 小工具
- 轻量级辅助脚本或其他实用工具
- 工作流说明、操作清单与常用参考记录
- 面向长期目标的专题分区，例如职业发展与教育成长

## 维护原则
仓库内容以简洁、清晰、便于检索为原则。新增内容应按用途归类，并尽量保持统一的记录方式与表达风格。
