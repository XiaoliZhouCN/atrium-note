# Career Growth Roadmap

这份 TODO 面向目标岗位：`图形渲染算法工程师 / 游戏引擎渲染工程师 / GPU图形算法工程师`

使用方式：
- `Daily Practice` 关注每天坚持的输入和训练。
- `Core Capability Tracks` 关注长期能力建设。
- `Learning Roadmap` 关注 2 年左右的阶段推进。
- `Project Roadmap` 关注作品集和工程落地。

# Daily Practice

目标：建立稳定、长期、低波动的成长节奏，避免只学项目、不补基础，或只学理论、不做输出。

## 每日最低配

- [ ] `30min` C++ 基础与工程语法复盘：现代 C++、STL、RAII、智能指针、模板、并发基础。
- [ ] `30min` 图形学/数学巩固：线性代数、坐标变换、矩阵、插值、概率统计、积分基础。
- [ ] `30min` 图形技术阅读：OpenGL / Vulkan / UE / FFmpeg / 图形论文 / 图形博客任选一项。
- [ ] `30min` 项目推进：哪怕只完成一个小函数、一个 shader、一个重构点，也要保持持续提交。

## 每周高频习惯

- [ ] 每周 `3` 道 LeetCode，重点放在数组、哈希、链表、树、二分、图、动态规划基础题，不追求刷题量，追求代码质量与稳定手感。
- [ ] 每周 `2` 次图形学公式手推或笔记整理，重点放在投影、BRDF、光照、滤波、色彩空间转换。
- [ ] 每周 `1` 次英文材料精读，目标是适应 API 文档、论文摘要、技术博客和工具文档阅读。
- [ ] 每周 `1` 次项目总结，记录本周完成、问题、下周动作，沉淀到文档或 log。
- [ ] 每周 `1` 次工具训练，轮换 `RenderDoc / Nsight / PIX / UE Profiler / ffmpeg CLI`。

## 每日可选加练

- [ ] `15min` 英语技术词汇复习，重点词汇：render pass、descriptor、barrier、radiance、tone mapping、gamut、profiling。
- [ ] `15min` 色彩科学巩固：Gamma、PQ、HLG、ICC、BT.709、BT.2020、白点、色域映射。
- [ ] `15min` 代码审美训练：阅读优秀渲染器、引擎模块、图形开源项目的目录和类设计。

# Core Capability Tracks

目标：构建 DreamJob 所需的核心能力，不把“会用工具”误当成“具备岗位能力”。

## 1. 图形学与数学基础

- [ ] 线性代数：向量、矩阵、基变换、特征值基础、仿射变换。
- [ ] 几何基础：平面、法线、射线、包围盒、空间关系。
- [ ] 光照数学：点乘、反射、半角向量、能量守恒、BRDF 基础。
- [ ] 概率积分：蒙特卡洛积分、重要性采样、方差概念。
- [ ] 色彩科学：Gamma、线性空间、色域、色温、HDR、ICC Profile。
- [ ] 目标：能够独立推导常见实时渲染与图像处理公式，而不是只会套代码。

## 2. 编程与工程能力

- [ ] C++：现代 C++、类设计、资源生命周期管理、模板与泛型、错误处理、并发。
- [ ] C#：为 Unity 和工具链做准备，重点掌握组件系统、编辑器脚本、工程代码组织。
- [ ] Python：用于资产处理、离线工具、数据处理、自动化脚本。
- [ ] CMake / Git：跨平台构建、依赖组织、版本管理、分支协作。
- [ ] 调试能力：日志、断点、调用栈、内存和资源泄漏排查。
- [ ] 目标：达到“能稳定维护中型图形工程”的工程素质。

## 3. 图形 API 与 GPU 能力

- [ ] OpenGL：状态机、纹理、FBO、后处理、uniform、VAO/VBO/EBO。
- [ ] Vulkan：资源绑定、同步、命令缓冲、render pass、pipeline。
- [ ] DirectX 12：descriptor heap、command list、resource barrier、PSO。
- [ ] Metal：资源模型、encoder、Apple 平台 GPU 工作方式。
- [ ] GPU 架构：warp/wave、带宽、缓存、overdraw、shader 开销。
- [ ] 目标：建立现代图形 API 的统一抽象视角，而不是停留在单 API 使用层。

## 4. Shader 与实时渲染能力

- [ ] GLSL / HLSL：顶点、片段、compute shader 的编写与调试。
- [ ] 实时渲染：PBR、阴影、IBL、后处理、TAA、Tone Mapping。
- [ ] 后处理体系：Bloom、Color Grading、AA、景深、边缘增强、颜色校正。
- [ ] GPU Profiling：定位 CPU/GPU 同步、瓶颈 pass、热点 shader、显存问题。
- [ ] 目标：从“能写 shader”升级到“能设计渲染模块与屏幕空间效果系统”。

## 5. 引擎与工具链能力

- [ ] UE5：材质系统、渲染管线、RHI、源码结构、插件开发、profiling。
- [ ] Unity：SRP/HDRP/URP 基础、渲染扩展方式、Editor 工具脚本。
- [ ] DCC 工具：Blender、Maya 或 Houdini 至少掌握一条基础资产流程。
- [ ] 美术协作：理解模型、贴图、法线、材质、烘焙、导出流程。
- [ ] 工具链：资产导入、批处理、自动化检查、可视化调试工具。
- [ ] 目标：从单兵写代码，提升到能支撑内容生产与团队协作。

## 6. 媒体与色彩链路能力

- [ ] FFmpeg：解封装、解码、像素格式、时间戳、帧同步、swscale。
- [ ] 图像处理：缩放、滤波、锐化、灰度、直方图、YUV/RGB 转换。
- [ ] 色彩管理：ICC、Gamma、HDR-SDR、PQ/HLG、BT.2020/BT.709。
- [ ] 跨平台：Windows / macOS 图形 API 与显示差异。
- [ ] 目标：构建图像/视频 GPU 处理与显示一致性的职业能力。

## 7. 高级图形算法与论文工程化

- [ ] GI：Probe GI、DDGI、Voxel GI、Lightmap Baking。
- [ ] 光追：DXR / Vulkan RT、反射、阴影、间接光。
- [ ] 论文复现：读论文、验证核心公式、做最小可行原型。
- [ ] 工程落地：性能调优、资源占用控制、项目接入、质量验证。
- [ ] 目标：具备“论文复现 -> 工程适配 -> 性能调优 -> 功能交付”的能力闭环。

## 8. AI 渲染与未来方向

- [ ] 超分与帧生成：DLSS、FSR、Frame Generation 的原理与接入方式。
- [ ] 神经图形：NeRF、Neural Materials、Neural Texture Compression。
- [ ] AI 工具工程化：资产处理、材质辅助生成、纹理增强。
- [ ] 深度学习基础：PyTorch 推理流程、模型部署、性能评估。
- [ ] 目标：形成 DreamJob 中高阶岗位要求的前沿竞争力。

# Learning Roadmap

目标：按阶段推进，不把所有技术同时展开，避免知识面很广但没有形成真正可交付能力。

## 阶段1：现在到入职后 3 个月

主题：新岗位胜任期

- [ ] 打牢 `C++ + 图形学数学 + 色彩管理 + FFmpeg 基础 + CMake/Git`。
- [ ] 能独立解释当前 OpenGLRenderer 中的视频预览链路、纹理上传链路、后处理链路。
- [ ] 补齐 FFmpeg 常用概念：demux、decode、pixel format、timestamp、frame queue。
- [ ] 补齐色彩链路概念：Gamma、线性空间、sRGB、BT.709、BT.2020、HDR-SDR。
- [ ] 把 OpenGLRenderer 的 `图像解码 / GPU纹理管理 / 视频帧上传` 结构拆得更清楚。

阶段目标：
- [ ] 能胜任图像/视频 GPU 加速岗位的日常开发。
- [ ] 能讲清楚一条完整的 `CPU解码 -> GPU上传 -> shader处理 -> 屏幕显示` 管线。
- [ ] 至少完成 `1` 次中等规模重构并写出设计说明。

## 阶段2：3 到 6 个月

主题：现代图形 API 统一抽象

- [ ] 系统补 `Metal / DirectX / Vulkan` 的现代 API 思维。
- [ ] 重点理解统一抽象：资源、同步、Pass、Pipeline、Command、Profiler。
- [ ] 通过最小 Demo 掌握 `Buffer / Texture / Descriptor / Barrier / Command Buffer`。
- [ ] 总结 OpenGL 与现代显式 API 的差异：状态机 vs 显式资源管理。

阶段目标：
- [ ] 能画出一张现代图形 API 的统一抽象图。
- [ ] 至少完成 `1` 个 Vulkan 或 DX12 最小渲染 Demo。
- [ ] 能解释 OpenGLRenderer 若迁移到 Vulkan，哪些模块必须重构。

## 阶段3：6 到 12 个月

主题：现代实时渲染能力建立

- [ ] 进入现代实时渲染主题：`PBR、阴影、TAA、Tone Mapping、Compute Shader、GPU Profiling`。
- [ ] 补 `RenderDoc / Nsight / PIX` 的性能分析基本方法。
- [ ] 理解 frame time、CPU bound、GPU bound、bandwidth bound、overdraw。
- [ ] 开始做真正“可展示”的渲染器级功能，而不是单个 shader 效果。

阶段目标：
- [ ] 完成一个支持 `PBR + Shadow + PostFX` 的渲染 Demo。
- [ ] 能独立对一个场景输出瓶颈分析报告。
- [ ] 能从视觉效果、性能、资源消耗三个维度评价一个渲染特性。

## 阶段4：12 到 18 个月

主题：引擎级渲染开发

- [ ] 重点突破 `UE5 + HLSL + 引擎源码 + 渲染模块定制`。
- [ ] 熟悉 UE5 的渲染结构、材质系统、渲染 pass 组织方式。
- [ ] 学习 HLSL 与引擎 shader 组织方式。
- [ ] 尝试做源码级修改或插件级扩展，例如自定义后处理或 profiling 工具。

阶段目标：
- [ ] 完成 `1` 个 UE5 渲染扩展项目。
- [ ] 能阅读并定位 UE 渲染模块中的关键代码路径。
- [ ] 能把“单项目经验”升级为“引擎模块开发经验”。

## 阶段5：18 到 24 个月

主题：高阶图形算法专项突破

- [ ] 攻坚 `GI / Lightmap / 光追 / 论文复现`。
- [ ] 至少精读 `3` 篇核心论文，并完成 `1` 个可运行原型。
- [ ] 学会控制论文方案的复杂度，先做 MVP，再做性能优化和工程接入。
- [ ] 训练从“研究概念”转成“可上线功能”的思维。

阶段目标：
- [ ] 至少完成 `1` 个可写进简历的高质量图形算法项目。
- [ ] 能清晰讲述：问题定义、方法选型、实现细节、性能结果、局限性。
- [ ] 具备 DreamJob 岗位中“论文复现到工程化”的核心竞争力。

## 阶段6：24 个月后

主题：AI 渲染与前沿方向扩展

- [ ] 扩展到 `AI渲染 / 神经压缩 / Frame Generation / AI工具工程化`。
- [ ] 学习图形与 AI 融合的落地方式，不局限于看概念。
- [ ] 关注推理性能、显存成本、资产流程接入和视觉收益评估。
- [ ] 逐步形成“传统渲染 + AI模块 + 工具链”组合能力。

阶段目标：
- [ ] 至少完成 `1` 个 AI 渲染或 AI 资产工具工程化项目。
- [ ] 能评估某个 AI 方案是否值得接入真实图形项目。
- [ ] 向 DreamJob 中最强的岗位要求靠拢。

# Project Roadmap

目标：通过有递进关系的项目，形成作品集、技术证明和面试叙事能力。

## 项目1：OpenGL 可扩展后处理框架

目标：
- [ ] 基于 OpenGL 做一个可扩展后处理框架，包含 `Bloom、Tone Mapping、Color Grading、TAA`。

需要习得的能力：
- [ ] FBO / RenderTarget 管理。
- [ ] 多 Pass 编排。
- [ ] shader 参数与配置管理。
- [ ] 屏幕空间效果调试与视觉验证。

工程进展标准：
- [ ] 初级完成：支持单个后处理效果开关与参数调整。
- [ ] 中级完成：支持多 Pass 串联与结果预览。
- [ ] 高级完成：支持配置驱动、效果注册和调试 UI。

## 项目2：图像/视频 GPU 处理链

目标：
- [ ] 完成 `FFmpeg解码 -> GPU纹理上传 -> 缩放 / 色彩转换 / HDR-SDR处理 -> 显示`。

需要习得的能力：
- [ ] FFmpeg 视频读取与帧队列。
- [ ] 动态纹理更新与 CPU/GPU 数据边界设计。
- [ ] 颜色空间转换与 Tone Mapping。
- [ ] 媒体播放同步与性能优化。

工程进展标准：
- [ ] 初级完成：视频可稳定播放，支持动态纹理更新。
- [ ] 中级完成：支持缩放、基础色彩转换、播放状态控制。
- [ ] 高级完成：支持 HDR-SDR 映射、色域转换、性能分析报告。

## 项目3：现代渲染器 Demo

目标：
- [ ] 使用 `Vulkan` 或 `DX12` 实现 `PBR + 阴影 + IBL + Compute后处理`。

需要习得的能力：
- [ ] 现代图形 API 的资源与同步管理。
- [ ] PBR 光照模型实现。
- [ ] 阴影、IBL、后处理组合。
- [ ] RenderDoc / Nsight 基础调试与验证。

工程进展标准：
- [ ] 初级完成：能稳定绘制模型并管理资源。
- [ ] 中级完成：具备 PBR、阴影、基础后处理。
- [ ] 高级完成：形成清晰模块结构与性能分析结果。

## 项目4：GPU 性能分析案例库

目标：
- [ ] 针对同一场景输出 `瓶颈定位 -> 优化策略 -> 前后对比数据`。

需要习得的能力：
- [ ] GPU Profiling 工具使用。
- [ ] 性能数据记录与解释能力。
- [ ] 优化实验设计能力。
- [ ] 形成“问题 -> 分析 -> 结论”文档表达能力。

工程进展标准：
- [ ] 初级完成：记录单个场景的 frame time 与热点 pass。
- [ ] 中级完成：给出至少 `3` 类优化方案及验证结果。
- [ ] 高级完成：形成可复用的 profiling 模板与案例库。

## 项目5：GI 专项项目

目标：
- [ ] 完成一个 `Probe GI / DDGI / Voxel GI / 简化 ReSTIR GI` 项目。

需要习得的能力：
- [ ] GI 理论理解与最小原型实现。
- [ ] 采样、缓存、更新策略设计。
- [ ] 视觉质量与性能平衡。
- [ ] 论文阅读与方案裁剪。

工程进展标准：
- [ ] 初级完成：实现核心算法最小原型。
- [ ] 中级完成：可在简单场景中稳定运行。
- [ ] 高级完成：具备性能优化、文档说明和作品展示材料。

## 项目6：UE5 源码级渲染扩展

目标：
- [ ] 完成一个 UE5 源码级渲染扩展，例如自定义后处理、材质通道、渲染 Pass 或 profiling 工具。

需要习得的能力：
- [ ] UE5 渲染模块阅读能力。
- [ ] HLSL 与引擎 shader 接入方式。
- [ ] 插件或源码改造组织方式。
- [ ] 与引擎工作流对齐的调试方式。

工程进展标准：
- [ ] 初级完成：能定位并修改一条渲染路径。
- [ ] 中级完成：扩展一个可实际使用的渲染功能。
- [ ] 高级完成：具备源码级说明文档、效果展示和性能验证。

## 项目7：AI 渲染集成项目

目标：
- [ ] 完成一个 AI 渲染集成项目，例如 `超分、神经贴图压缩、AI材质辅助生成` 的工程接入。

需要习得的能力：
- [ ] 推理模型接入与调用。
- [ ] 图形项目中的资源流程整合。
- [ ] 模型性能与视觉收益评估。
- [ ] 形成“AI模块不是展示品，而是生产工具”的工程思维。

工程进展标准：
- [ ] 初级完成：完成一个 AI 模块的离线接入验证。
- [ ] 中级完成：形成可重复执行的工具流程。
- [ ] 高级完成：具备实际项目可用性评估和对比报告。
