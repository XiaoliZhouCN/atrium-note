# Dream Job 岗位整理

## Technology Platform-游戏引擎研发工程师-(渲染效果)

### 岗位职责

1. 负责全局光照（GI）系统的前沿技术预研与工程落地，包括实时 GI 与离线烘焙方案；
2. 设计并实现光照烘焙管线，优化 Lightmap 质量、烘焙效率与内存占用；
3. 开发高品质渲染效果，包括体积光、AO、反射探针、间接光照等；
4. 持续追踪学术界与工业界最新成果（SIGGRAPH/GDC/Eurographics），主导前沿技术的原型验证与产品化落地；
5. 与美术团队紧密配合，制定光照工作流与场景表现标准。

### 岗位要求

1. 5 年以上 3D 引擎开发经验，精通 UE 或 Unity 引擎光照与渲染模块；
2. 扎实的数学基础（球谐函数、蒙特卡洛积分、辐射度量学）；
3. 深入理解全局光照理论（Path Tracing、Radiosity、Light Probe 等）；
4. 熟悉 GPU/CPU 架构，具备 Shader 开发与优化能力（HLSL/GLSL/Metal）；
5. 有 Lightmap 烘焙管线或实时 GI 系统开发经验；
6. 有将前沿图形学技术（如 Lumen、DDGI、ReSTIR、Surfel GI、Neural Radiance 等）从论文/原型落地到实际项目的成功经验，能独立完成“论文复现→工程适配→性能调优→产品上线”全流程；
7. 有移动端光照适配经验者优先；有 UE5 3A 级 PC 端游戏开发经验者更佳；
8. 有 AI 辅助编程实践经验，具备 AI 工程化落地的系统性方法论者加分。

## 图形渲染资深工程师-UE方向

### 岗位职责

1. 负责基于 Unreal Engine 渲染管线的技术研发与性能优化，针对项目需求对 UE 底层源码进行定制化修改与扩展；
2. 将深度学习方法与传统图形算法结合，设计并实现实时渲染方案，以提升画面质量与运行性能；
3. 阅读、分析并实现图形学前沿学术论文，将研究成果工程化并集成到产品/项目中；
4. 与工具链、美术 TA 及产品团队协作，推动渲染功能从设计到交付的落地。

### 岗位要求

1. 计算机图形学、计算机科学、人工智能或相关专业本科及以上学历，3 年及以上相关工作经验；
2. 精通 Unreal Engine 渲染架构，具备 UE 底层源码阅读、修改与定制开发能力，有引擎改造或插件开发实战经验；
3. 扎实掌握实时渲染核心算法与技术，包括光栅化、光线追踪、后处理流程、材质与着色器编程等；
4. 精通 C++，熟练编写和调试 HLSL/GLSL 等 shader 代码；
5. 具备良好的沟通协作能力与工程化意识，热衷学习新技术并能将研究成果落地。

### 加分项

1. 有帧生成（frame generation）、神经材质（neural materials）、AI 驱动光照等前沿图形学项目经验；
2. 熟悉 GPU 并行计算与性能优化（CUDA、Metal、Vulkan/Spir-V 等）；
3. 在顶会/期刊（如 SIGGRAPH、EG、ICCV、CVPR、TOG 等）有论文发表或实现开源项目经验；
4. 熟练使用深度学习框架（PyTorch、TensorFlow 等），能够完成模型训练、推理及工程化性能优化。

### 岗位亮点

1. 参与前沿图形渲染技术的研发与落地，有机会接触并应用最新的渲染技术和算法；
2. 与行业内顶尖技术团队合作，共同打造高质量、高水准的视觉体验；
3. 提供具有竞争力的薪资待遇和广阔的职业发展空间；
4. 工作环境开放包容，鼓励技术创新与个人成长。

## 游戏引擎开发资深工程师-AI渲染

### 岗位职责

1. 负责 RTX 光线追踪技术的引擎集成工作，包括 Vulkan/DXR 渲染管线集成、实时光追渲染（反射、阴影、全局光照）、DLSS 超分辨率和帧生成技术集成；
2. 负责引擎渲染架构重构工作，设计并实现双渲染后端（传统 + RTX），支持多后端无缝切换，确保兼容性和稳定性；
3. 负责 AI 资产工具的工程集成，包括纹理超分（Real-ESRGAN 等）、材质自动转换（PBR 材质生成）、神经贴图压缩（Neural Texture Compression）等工具的集成和自动化管线开发；
4. 负责游戏渲染性能优化工作，针对 RTX 模式进行深度性能分析和优化，确保稳定 60fps，提升游戏表现力；
5. 负责制定引擎工具链方案，帮助研发团队提升研发效率；
6. 负责游戏中性能优化相关工作，针对需求定制增强游戏引擎底层功能；
7. 负责图形兼容性分析以及疑难问题的分析定位工作。

### 岗位要求

1. 3 年以上手机游戏引擎开发和维护经验，深刻理解 3D 游戏引擎架构，精通引擎接口和游戏制作流程；
2. 熟悉 3D 图形学，有良好的数学和算法基础；
3. 熟练掌握 3D 图形渲染技术，精通 Shader 相关开发；
4. 精通 Vulkan 或 DirectX 12 现代图形 API，有实际项目落地经验，熟悉渲染管线设计和性能优化；
5. 有光线追踪技术（DXR/Vulkan Ray Tracing）实际项目经验，熟悉光追渲染管线和性能优化；
6. 有引擎深度集成和工程落地经验，能够独立完成复杂技术方案的设计和实施；
7. 责任心强，善于沟通，对游戏前沿技术有热情；
8. 熟悉商业游戏引擎源代码，热爱游戏优先。

### 加分项

1. 有 AI 工具集成和落地经验，如纹理超分（Real-ESRGAN、ESRGAN）、材质生成（Substance、MaterialGAN）、神经贴图压缩（Neural Texture Compression）等工具的实际项目应用；
2. 有自动化工具链开发经验，能够设计和实现美术资产自动化处理管线，提升美术资产制作效率；
3. 了解神经渲染技术，如 Neural BRDF、Neural Radiance Fields（NeRF）、Neural Texture Compression 等前沿技术，有论文阅读或复现经验；
4. 有 NVIDIA RTX 技术栈使用经验，如 RTX Remix、Omniverse、RTX SDK 等工具或平台的使用经验；
5. 有游戏引擎源码级开发经验，如 UE4/UE5、Unity、自研引擎等，熟悉引擎架构和渲染模块；
6. 有性能优化和调试经验，熟练使用 RenderDoc、NSight Graphics、PIX 等 GPU 调试工具；
7. 有技术分享和开源贡献，如 SIGGRAPH/GDC 分享；
8. 有跨平台开发经验，熟悉 PC、主机（PS5/Xbox）等多平台渲染技术。

### 岗位亮点

1. 成熟的产品体系，与业界顶尖人才共事；
2. 参与具有挑战性和创新性的游戏项目，提升个人技术水平和行业影响力；
3. 竞争力的薪资待遇和完善的福利体系；
4. 提供广阔的职业发展空间和学习机会，助力职业成长。

3. 优化美术 pipeline 并开发 DCC 和引擎工具，提高美术工作效率；

5. 跟进版本、工程，定位、解决相关 Bug；
6. 跟进和评估技术方案的落地，探索高品质渲染效果，前沿技术方案的探索和测试。

### 岗位要求

1. 至少 3 年以上游戏从业经验，具有良好的引擎开发能力，了解美术各模块生产流程；
2. 具备较好的审美能力，能和美术有效沟通协作；

5. 熟悉常见性能优化手段，如 DrawCall、Shader 复杂度、纹理与内存优化及引擎常用优化技术；
6. 较好的编程功底，熟练掌握 C++、Python 等 UE 相关编程语言，掌握 CG、HLSL、GLSL 至少一种 Shader 语言；

8. 有一定抗压能力，在项目冲刺阶段能够保持高效和专注；
9. 良好的自驱力、独立解决问题的能力，和对新技术的研发和探索能力。

### 加分项

1. 具有 UE 手游经验；
2. 图形程序、计算机科学、数字媒体相关专业。
