# Study Abroad

## 定位
`study_abroad` 是 `education` 分区下的阶段性主题目录，用于维护留学申请、院校筛选、申请节奏与相关专题材料。

当前阶段目标：
- 工作 `3` 年后申请德国 `TU9` 院校。
- 重点关注数字媒体技术及相关专业方向。

## 当前结构
- `application_materials/`：申请材料、准备清单、版本规划与投递资料索引。

## 后续可扩展方向
- `target_programs/`：记录目标院校、专业与要求对比。
- `timeline/`：记录申请时间线、准备节奏与关键节点。
- `finances/`：记录预算、奖学金、生活成本与资金规划。

## 维护原则
- 留学申请只作为 `education` 的一个阶段目标，不与长期语言和专业课程能力混在同一层。
- 优先整理路径、差距、清单与版本索引，不在本仓库存放大量过程性草稿。
