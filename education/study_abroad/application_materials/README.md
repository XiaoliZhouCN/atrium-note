# Application Materials

## 定位
这里用于整理申请材料本身，而不是泛化记录所有留学信息。

当前处于 `education/study_abroad/` 之下，表示它服务于留学申请这一阶段性目标。

## 当前建议范围
- 通用材料：简历、动机信/个人陈述、语言成绩、成绩单、学位材料。
- 支撑材料：推荐信、课程描述、项目说明、作品集索引。
- 版本管理：区分通用版本、院校定制版本、最终投递版本。
- 清单跟踪：记录每项材料的完成状态、缺口与更新时间。

## 建议后续补充
- 按材料类型建立模板与版本命名规则。
- 按院校或项目记录特殊要求。
- 整理翻译、公证、盖章、扫描件等行政流程要求。

## 使用原则
- 先建立清单和命名规范，再放入具体材料。
- 任何会频繁修改的正式申请文本，后续更适合放在独立仓库单独维护。
