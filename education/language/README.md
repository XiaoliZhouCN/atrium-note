# Language Skills

## 定位
这里不只记录雅思备考，而是作为长期维护的语言能力分区。

当前规划：
- 以英语为主，整理已有雅思备考经验、表达素材与能力短板。
- 后续可自然扩展到德语，而不需要重建目录结构。

## 建议维护框架

### English
- 听力：听辨能力、学术讲座、技术主题听力。
- 口语：自我介绍、项目表达、专业课解释、申请面试表达。
- 阅读：院校官网、项目介绍、学术材料、技术文档。
- 写作：邮件、SOP/PS、简历描述、课程说明。
- 词汇：技术英语、申请英语、学术常用表达。

### German
- 学习目标等级。
- 课程与资料来源。
- 每阶段复习计划。
- 常见申请/生活表达。

## 维护原则
- 已完成的雅思资料优先提炼为方法总结，而不是原样堆放。
- 语言训练尽量围绕 `申请表达 + 专业表达 + 学术阅读` 三类真实场景展开。
