# Education

## 分区定位
`education` 用于长期维护语言能力、专业课程能力、学术衔接与阶段性深造目标相关的整理文档、清单、索引和结构化资料。

当前主线：
- 把语言与专业课程整理成贯穿整个学习和工作生涯的长期能力资产。
- 让后续的留学申请、研究生衔接、学术阅读和项目表达都能复用这一分区内容。
- 当前阶段重点目标为工作 `3` 年后申请德国 `TU9` 院校，关注数字媒体技术及相关专业方向。
- 在本仓库中只保留框架、总结、清单、json 与索引型文档。
- 具体项目实践、材料打磨或专题整理，后续放到独立仓库管理。

## 目录结构
- `language/`：语言能力整理，当前以英语为主，后续可扩展德语。
- `academics/`：专业课与 APS 相关复习整理，作为长期维护的知识区。
- `study_abroad/`：围绕下一个主要人生阶段目标维护留学专题内容。
- `logs/`：按日、周、月记录推进情况。
- `TODO.md`：持续更新的行动清单。

## 维护原则
- 不把分区设计成一次性考试资料夹，而是做成可长期维护的教育能力与行动空间。
- 先沉淀结构，再逐步补充内容，避免一开始堆大量零散文件。
- 以“可检索、可复用、可迁移”为标准组织文档。
- 优先记录结论、路径、清单和复盘，而不是只堆原始资料。

## 当前阶段建议
- 先搭好英语、专业课、留学申请三条主线。
- 后续再按需要在 `study_abroad/` 下增加 `target_programs`、`timeline`、`finances` 等子分区。
