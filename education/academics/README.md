# Academics

## 定位
`academics` 用于维护专业课复习与知识整理，是 `APS` 准备的核心入口，但不会只服务于 APS。

这个分区同时服务以下目标：
- APS 面试与材料准备。
- 申请时对本科课程背景的系统梳理。
- 未来研究生学习前的知识衔接。
- 个人长期专业知识沉淀。

## 建议内容结构
- 课程索引：列出本科核心课程与关联主题。
- 课程笔记：按课程整理重点概念、公式、方法和案例。
- 面试表达：准备每门课如何用清晰语言解释“学了什么、做了什么、理解了什么”。
- 关联项目：记录课程知识与实际项目、实验、作品之间的对应关系。

## 优先方向
- 数学基础：高数、线代、概率统计、离散数学。
- 计算机基础：数据结构、算法、操作系统、计算机网络。
- 数字媒体相关：图形学、图像处理、视频处理、多媒体技术、人机交互。
- 编程与工程：C/C++、Python、软件工程、项目实践。

## 维护原则
- 先整理课程框架和知识图谱，再逐步补充细节。
- 每门课尽量回答四个问题：`核心内容是什么`、`为什么重要`、`我掌握了什么`、`如何和未来方向关联`。
